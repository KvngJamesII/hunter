# QuicRef

QuicRef is a microtask platform: create tasks, complete them for pay, and earn through referrals. It includes a user dashboard, wallet, and admin tools for payments and users.

## Features

- Task creation, submission, and review
- Wallet deposits and withdrawals
- Referral bonuses
- Admin panel for users and payments

## Stack

React, TypeScript, Express, Firebase, Tailwind, shadcn/ui

This repository is a public showcase of the QuicRef platform.
